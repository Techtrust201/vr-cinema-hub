Guide client · Windows seulement

Installer l’application DLPAlexandre sur un casque Quest

Une étape à la fois. Ne passez à la suivante que lorsque vous voyez la phrase écrite en vert. Le câble sert à installer. Les films passent ensuite par le Wi-Fi, et restent dans le casque sans Internet.

Posez ceci sur la table

  • Un PC Windows 10 ou 11.
  • Le téléphone sur lequel l’application Meta Horizon est installée, et où le casque apparaît déjà.
  • Le casque (Quest 2, 3, 3S ou Pro), allumé, chargé à plus de 50 %.
  • Un câble USB qui copie des fichiers. Celui de la boîte du Quest ne fait souvent que charger : prenez un câble déjà utilisé pour récupérer des photos d’un téléphone.
  • L’adresse e-mail et le mot de passe du site VR Cinema Hub. Ce compte n’est pas le compte Meta. S’il ne vous a pas été donné, arrêtez-vous et demandez-le.
  • Le fichier DLPAlexandre.apk, à télécharger sur le site, voir ci-dessous.

Télécharger l’application

  1. Sur le PC, ouvrez le site et connectez-vous avec le compte VR Cinema Hub. https://vr-cinema-hub.vercel.app
  2. Menu de gauche, Casques. En haut de la page, le cadre Application casque DLPAlexandre indique la version et la date de sa dernière mise à jour.
  3. Cliquez sur Télécharger DLPAlexandre.apk. Le fichier arrive dans le dossier Téléchargements du PC.

Page Casques du site. Le téléchargement est le bouton violet dans le cadre Application casque.

Téléchargez-le le jour même : le site propose toujours la dernière version. Si Windows l’a nommé DLPAlexandre (1).apk, c’est qu’il était déjà là : supprimez l’ancien et renommez le nouveau en DLPAlexandre.apk.

La règle qui fait rater toute l’installation

Le casque, le téléphone et le site développeur Meta doivent utiliser le même compte Meta. Ouvrez les paramètres du casque et notez l’adresse affichée. C’est celle-là, pas une autre, que vous utiliserez aux étapes 1, 2 et 3. Trois comptes différents : le reste du guide ne produit rien, sans message d’erreur clair.

Deux associations, ne les mélangez pas

Téléphone et casque. C’est Meta. C’est déjà fait si le casque apparaît dans l’application du téléphone. On ne vous demandera pas de code pour ça.

Casque et site VR Cinema Hub. C’est plus tard, étape 7. Le bouton s’appelle Appairer un casque. Il est sur le site web, dans le menu Casques. Il n’existe pas dans Meta Quest Developer Hub, ni dans l’application Meta Horizon du téléphone.

Étape 1 · une seule fois par compte

Créer l’équipe Meta

Sans cette étape, la ligne « Mode développeur » n’existe pas dans le téléphone. Le guide précédent sautait cette page. C’est pour ça que l’installation s’arrêtait avant même le câble.

  1. Sur le PC, ouvrez Chrome ou Edge. Connectez-vous avec le compte Meta du casque, celui que vous avez noté. https://developers.meta.com/horizon/manage/organizations/create/
  2. Créez une équipe. Un nom suffit, par exemple celui de votre société. Vous pouvez être seul dans l’équipe. Validez jusqu’au bout.
  3. Ouvrez ensuite la page de vérification. https://developers.meta.com/horizon/manage/verify/
  4. Vérifiez le compte. Meta propose deux façons : confirmer votre numéro de mobile par SMS, ou ajouter une carte bancaire. PayPal ne compte pas. Le titulaire du compte doit avoir 18 ans ou plus.
  5. Attendez que la page indique que le compte est vérifié. Si un e-mail ou un SMS est demandé, faites-le maintenant, avant de toucher au casque.
Passez à l’étape suivante

La page de vérification affiche que le compte est vérifié, et vous avez bien une équipe à votre nom.

Arrêtez-vous si

vous n’arrivez pas à vous connecter avec le compte du casque, ou si le site refuse la vérification. Inutile de brancher le casque : le mode développeur restera invisible. Reprenez avec le bon compte, ou demandez à la personne qui gère le compte Meta de faire cette page à votre place.

Étape 2 · une fois par casque

Activer le mode développeur

Cela se fait sur le téléphone, dans l’application Meta Horizon. Pas dans le casque, pas sur le PC.

  1. Ouvrez Meta Horizon sur le téléphone. Le compte connecté doit être celui du casque.
  2. Si le casque n’apparaît pas dans l’application, associez-le d’abord avec le parcours normal de Meta (l’application vous guide). Ce n’est pas le code à 6 chiffres. Revenez ici seulement quand le nom du casque est visible.
  3. Touchez l’icône de casque dans la barre du bas.
  4. Touchez la ligne du casque elle-même (Quest 3, Quest 3S, etc.). La voir en haut de l’écran ne suffit pas.
  5. Sous la photo du casque, touchez Paramètres du casque. En anglais : Headset Settings.
  6. Touchez Mode développeur. En anglais : Developer Mode.
  7. Mettez l’interrupteur sur activé. Sortez de l’écran, rouvrez-le : l’interrupteur doit être resté activé.

Téléphone, application Meta Horizon. L’icône de casque est à droite dans la barre du bas. Ces images viennent de la documentation Meta, en anglais.

Touchez la ligne du casque elle-même, ici « Meta Quest 3 ».

Puis Headset settings. En français : Paramètres du casque.

Dans ce menu, Developer Mode. En français : Mode développeur.

Sur cette image l’interrupteur est encore à gauche, donc éteint. Poussez-le vers la droite : il doit rester activé.

Passez à l’étape suivante

L’interrupteur Mode développeur est activé, et il le reste quand vous revenez sur l’écran.

La ligne « Mode développeur » n’existe pas

Ne cherchez pas plus loin dans les menus. Revenez à l’étape 1. Les trois causes, dans l’ordre : le téléphone n’est pas connecté avec le compte du casque ; le compte n’est pas vérifié ; aucune équipe n’a été créée. Tant que la ligne est absente, le PC ne pourra pas installer l’application.

Étape 3 · une seule fois par ordinateur

Installer le programme sur le PC

Le programme s’appelle Meta Quest Developer Hub. C’est lui qui installe l’application, avec la souris. Vous n’aurez pas de commande à taper.

  1. Sur le PC, ouvrez cette page et téléchargez la version Windows. https://developers.meta.com/vr/downloads/package/oculus-developer-hub-win/
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis Exécuter quand même.
  3. Installez le programme avec les boutons proposés, puis ouvrez-le.
  4. Connectez-vous avec le même compte Meta que le casque et le téléphone.
  5. Avant de brancher le casque : regardez en bas à droite de l’écran, la petite flèche ^. S’il y a une icône Meta ou Oculus, clic droit, Quitter. Ce programme (Quest Link) prend le câble et le casque reste invisible. Fermez-le à chaque installation.

La bonne page de téléchargement. Le bouton s’appelle Télécharger, à droite du titre Meta Quest Developer Hub for Windows.

Passez à l’étape suivante

Meta Quest Developer Hub est ouvert et vous y êtes connecté. Quest Link est fermé, y compris dans la zone près de l’horloge.

Étape 4 · le point où ça bloque d’habitude

Brancher le casque et l’autoriser

La question d’autorisation s’affiche dans le casque, pas sur l’écran du PC. Si vous regardez le moniteur, vous ne la verrez pas.

  1. Branchez le câble sur un port USB à l’arrière de l’ordinateur, directement. Pas sur un hub, pas sur le clavier, pas sur l’écran.
  2. Mettez le casque sur la tête.
  3. Si une fenêtre propose Quest Link ou Air Link : refusez. Choisissez Annuler, Pas maintenant ou Refuser. Link empêche l’installation.
  4. Une fenêtre demande d’autoriser le débogage USB. Cochez Toujours autoriser cet ordinateur (en anglais : Always allow from this computer). Puis Autoriser.
  5. Si une seconde fenêtre demande l’accès aux fichiers du casque, acceptez-la aussi.
  6. Enlevez le casque. Restez dans la fenêtre Meta Quest Developer Hub, celle de l’étape 3. Ce n’est pas un menu de Windows.

Cette fenêtre s’affiche dans le casque. Cochez Always allow from this computer (Toujours autoriser cet ordinateur), puis OK.

Où cliquer : Device Manager

Device Manager est une ligne dans ce programme, en anglais. Ce n’est pas le Gestionnaire de périphériques de Windows. Si une fenêtre liste le clavier, l’écran et la souris, fermez-la : ce n’est pas la bonne.

  1. Si le programme est fermé : bouton Démarrer, tapez Meta Quest, ouvrez Meta Quest Developer Hub. Pas « Meta Quest Link ».
  2. Agrandissez la fenêtre au maximum, carré en haut à droite. Sinon la colonne de gauche ne montre que des dessins, sans les mots.
  3. Regardez la bande verticale tout à gauche de cette fenêtre.
  4. Cliquez sur les mots Device Manager. S’il n’y a qu’une icône, c’est celle qui dessine un casque. Laissez la souris dessus : une bulle affiche Device Manager.
Passez à l’étape suivante

Le milieu de la fenêtre parle du casque, avec une pastille verte Active. S’il n’y est pas, restez ici. N’envoyez pas le fichier.

Aucune fenêtre dans le casque

  1. Gardez le casque sur la tête. Appuyez sur le bouton Meta de la manette droite (le bouton avec le logo).
  2. Touchez l’engrenage Paramètres.
  3. Ouvrez la rubrique Développeur.
  4. Activez la ligne qui parle de la connexion USB, ou Notification MTP.
  5. Débranchez le câble. Comptez jusqu’à cinq. Rebranchez-le, le casque toujours sur la tête.
  6. Cochez « Toujours autoriser », puis Autoriser.
Vous aviez déjà cliqué sur Refuser

Dans le casque : Paramètres → Développeur → Révoquer les autorisations de débogage USB. Débranchez, rebranchez, et acceptez cette fois en cochant « toujours ».

Device Manager reste vide

Changez de câble, puis de port USB à l’arrière. Redémarrez le casque (appui long sur le bouton d’alimentation, Éteindre, rallumez). Vérifiez que Quest Link est bien quitté. Si l’écran est toujours vide, allez à la dernière page de ce guide, « Secours », et faites uniquement la partie pilote. Revenez ici ensuite.

Étape 5

Envoyer le fichier dans le casque

Un double-clic sur le fichier .apk ne l’installe pas. Windows ne sait pas l’ouvrir. Seul le programme Meta Quest Developer Hub peut l’envoyer au casque.

  1. Ouvrez le dossier Téléchargements et copiez DLPAlexandre.apk sur le Bureau, pour le retrouver tout de suite. Pas encore téléchargé : première page de ce guide, « Télécharger l’application ».
  2. Dans l’Explorateur, menu Affichage → Afficher → cochez Extensions de noms de fichiers. Le nom doit finir par .apk. S’il finit par .zip, ce n’est pas encore le bon fichier.
  3. Le casque est branché. Dans Meta Quest Developer Hub, fenêtre en plein écran, colonne de gauche, cliquez Device Manager (ou l’icône casque). La pastille doit être verte, mot Active. Sinon cliquez sur la carte du casque, remettez-le, et acceptez à nouveau le débogage USB.
  4. Dans cette même page, trouvez la zone Apps. Cliquez sur Add Build. Ne faites pas glisser le fichier : le bouton se trompe moins.
  5. Dans la fenêtre qui s’ouvre, cliquez sur Bureau à gauche. Cliquez une fois sur DLPAlexandre.apk, puis sur Ouvrir.
  6. Attendez. Cela prend une à deux minutes. Ne débranchez pas. Ne fermez pas le programme. Une notification Windows dit que l’installation est finie, et le nom DLPAlexandre apparaît dans la liste Apps.

Dans Device Manager, l’onglet s’appelle Apps. Le bouton à utiliser est Add Build, encadré en jaune. Pas un double-clic sur le fichier.

Passez à l’étape suivante

Le nom DLPAlexandre est visible dans la liste Apps du programme, sur le PC. Tant qu’il n’y est pas, le casque n’a rien reçu : ne cherchez pas l’application dans le casque.

Le programme affiche une erreur

Ne recommencez pas dix fois. Photographiez le message.

S’il contient INSTALL_FAILED_UPDATE_INCOMPATIBLE : une ancienne version est déjà dans le casque. N’effacez rien. Appelez votre prestataire.

S’il dit que le casque n’est pas connecté : retour à l’étape 4. Le fichier n’a pas été envoyé.

Vous pouvez débrancher

Seulement une fois le nom visible dans Apps. Le câble ne sert plus, sauf pour un autre casque.

Étape 6 · c’est ici que l’application semble « absente »

Ouvrir l’application dans le casque

Elle n’est pas sur l’écran d’accueil, ni dans la liste normale des jeux. Meta la range à part. Si vous ne faites pas le chemin ci-dessous, vous concluez que l’installation a échoué alors qu’elle a réussi.

Comment cliquer

Gardez le casque sur la tête. Manette droite : le bouton avec le logo, sous le pouce, ouvre le menu. Pour choisir une ligne, pointez-la avec la manette et pressez la gâchette, sous l’index. Tous les clics de cette page se font ainsi.

Chemin A — menu récent

  1. Bouton logo de la manette droite.
  2. Dans la barre du bas, Bibliothèque. En anglais : Library.
  3. À gauche, Menu.
  4. Sources inconnues. En anglais : Unknown Sources.
  5. DLPAlexandre.

Chemin B — si « Menu » n’existe pas à gauche

  1. Bouton logo, puis Bibliothèque.
  2. À gauche, touchez Applications. Pas « Tous », pas « All ». La ligne Sources inconnues n’apparaît pas tant que vous restez sur Tous.
  3. En haut de la page, ouvrez la liste qui affiche Tous, All ou Installées.
  4. Choisissez Sources inconnues / Unknown Sources.
  5. DLPAlexandre.
La ligne « Sources inconnues » n’existe nulle part

Faites ces quatre gestes dans l’ordre, puis recommencez le chemin A et le chemin B.

1. Vous devez être sur le profil principal, pas un invité. Bouton logo → icône de personne. S’il y a plusieurs noms, prenez le premier, celui du compte qui a le mode développeur.

2. Éteignez vraiment le casque. Appui long sur le bouton d’alimentation (pas le bouton logo) → Éteindre. Comptez jusqu’à dix. Rallumez.

3. Sur le téléphone, coupez Mode développeur. Éteignez le casque, rallumez-le. Réactivez Mode développeur. Éteignez et rallumez encore.

4. Si la ligne manque toujours, le fichier n’est pas dans le casque. Retour à l’étape 5 : le nom DLPAlexandre doit être dans la liste Apps du PC.

La première fois, des fenêtres s’interposent

Zone de jeu : choisissez Stationnaire si on vous le propose, sinon tracez le minimum demandé. Une demande d’autorisation : Autoriser. Une demande pour une application de source inconnue : acceptez. Ensuite seulement, l’écran avec le code apparaît.

Passez à l’étape suivante

DLPAlexandre est ouvert et un code à 6 chiffres est affiché. Laissez cet écran. Ne quittez pas l’application. Pour la rouvrir plus tard, refaites le chemin A ou B : elle ne sera toujours pas sur l’écran d’accueil.

Étape 7

Relier le casque au site

Le bouton n’est pas dans Meta Quest Developer Hub

Meta Quest Developer Hub sert à envoyer le fichier .apk. L’application Meta Horizon du téléphone sert au mode développeur. Aucun des deux n’a de bouton Appairer. Le code à 6 chiffres se tape sur le site, dans la fenêtre ci-dessous.

Le câble ne sert plus. Le casque a besoin du Wi-Fi.

Sur le site vr-cinema-hub.vercel.app, menu de gauche. Cliquez sur Casques, la ligne violette. Sur un petit écran, ouvrez d’abord le menu avec les trois traits en haut à gauche.

Le bouton violet « Appairer un casque » est en haut à droite de cette page. Le bouton « Télécharger » à côté sert au fichier, pas à l’appairage.

  1. Le Wi-Fi se branche avant de taper le code. Bouton logo → engrenage Paramètres → Wi-Fi → votre réseau. S’il en existe deux du même nom, prenez celui qui finit par 5G ou 5 GHz. Attendez qu’il indique connecté. Rouvrez ensuite DLPAlexandre par le chemin A ou B de l’étape 6 si le code n’est plus à l’écran.
  2. Sur le PC, ouvrez le site et connectez-vous avec le compte VR Cinema Hub (pas le compte Meta). https://vr-cinema-hub.vercel.app
  3. Dans le menu de gauche, cliquez sur Casques.
  4. Cliquez sur Appairer un casque.
  5. Tapez les 6 chiffres. Donnez un nom que vous reconnaîtrez le jour J, par exemple « Accueil 1 » ou « Salle Paris ».
  6. Cliquez sur Appairer. Attendez quelques secondes sans fermer l’application dans le casque.

Cette fenêtre s’ouvre sur le site. Le 123456 affiché en gris est un exemple : effacez-le et tapez le code montré dans le casque. Puis un nom, puis Appairer.

Passez à l’étape suivante

Dans le casque, l’écran du code a disparu. Sur le site, le nom que vous avez choisi apparaît dans la liste des casques.

Le code est refusé ou a expiré

Bouton logo, quittez DLPAlexandre avec la croix, puis rouvrez-la par le chemin A ou B de l’étape 6. Un nouveau code s’affiche. L’ancien ne marchera plus. Retapez-le tout de suite, le Wi-Fi restant connecté.

Étape 8

Mettre un film dans le casque

Déposer le film

  1. Sur le site, menu Bibliothèques.
  2. Choisissez l’onglet Location ou Animations, selon le film.
  3. Cliquez sur Uploader des vidéos et choisissez le fichier. Laissez l’onglet ouvert jusqu’à 100 %. Ne mettez pas le PC en veille. Si l’envoi est coupé, il reprend du début.
  4. Si le site demande ce que montre l’image :
    • Tout autour du spectateur — on peut regarder derrière soi.
    • La moitié devant le spectateur — seulement l’avant.
    • Un écran devant le spectateur — comme une toile de cinéma.
    Pour le relief : deux images l’une au-dessus de l’autre → deux yeux superposés. Deux images côte à côte → deux yeux côte à côte. Une seule image → sans relief.
  5. Regardez l’aperçu. Une image en damier ou coupée en deux veut dire que le relief est faux : corrigez-le avant d’envoyer.

Page Bibliothèques. Onglets Location et Animations, zone de dépôt, bouton Uploader des vidéos.

L’attribuer au casque

  1. Menu Playlists. Tapez un nom, par exemple « Salon », puis Créer.
  2. Cliquez sur Éditer.
  3. Dans la colonne Vidéos, cliquez sur chaque film à inclure. Une coche verte confirme.
  4. Dans la colonne Diffuser à, cliquez sur le nom du casque.
  5. Cliquez sur Fermer. C’est déjà enregistré, il n’y a pas d’autre bouton.

Page Playlists. Le nom se tape à gauche, le bouton Créer est à droite. Éditer est sur la carte.

Après Éditer : colonne Vidéos à gauche, colonne Diffuser à à droite, bouton Fermer en haut.

Plusieurs casques, les mêmes films

Menu Groupes. Créez un groupe, par exemple « Salle A ». Cliquez sur Gérer les membres et cliquez sur chaque casque à y mettre. Ensuite, dans la playlist, cochez le groupe plutôt que les casques un par un. Un casque ajouté plus tard au groupe reçoit les films tout seul.

Page Groupes. Créer en haut à droite, Gérer les membres sur la carte.

Gérer les membres ouvert. Une coche verte veut dire que le casque est dans le groupe. Fermer replie la liste.

Attendre que le casque ait vraiment les films

  1. Casque allumé, Wi-Fi connecté, branché sur secteur, et DLPAlexandre ouvert. S’il est fermé, le téléchargement n’existe pas. Rouvrez-le par le chemin A ou B de l’étape 6, pas depuis l’écran d’accueil.
  2. Sur le site, menu Suivi sync. Cliquez sur Rafraîchir.
  3. Attendez l’état À jour. C’est le seul état qui veut dire « les films sont dans le casque ».

Menu Suivi sync. Rafraîchir en haut à droite. Analyser et Forcer la mise à jour sont sur la ligne du casque.

Le casque s’endort et le téléchargement s’arrête

Dès que vous l’enlevez, il se met en veille en une quinzaine de secondes et suspend le téléchargement. Pendant le premier remplissage, reposez-le sur la tête toutes les une à deux minutes, jusqu’à À jour. Faites ça la veille, pas le matin de l’événement. Un film pèse souvent plus d’un gigaoctet.

Le sujet d’un film 360 n’est pas face au spectateur

Au lancement, le casque place devant le spectateur le centre de l’image. Si le tournage a mis le sujet ailleurs, réglez-le une fois pour toutes, sans renvoyer le film.

  1. Casque sur la tête, lancez le film. Notez où vous voyez le sujet au démarrage : à droite, à gauche, derrière vous.
  2. Sur le site, Bibliothèques, icône de curseurs sur la ligne du film.
  3. Sous « le sujet du film apparaît », cliquez sur À droite, À gauche ou Derrière, ou ajustez le curseur au degré près. Puis Enregistrer.
  4. Attendez À jour dans Suivi sync, relancez le film : le sujet est devant vous. Le casque ne retélécharge pas le film.

Icône de curseurs sur la ligne du film. Le sujet se règle avec À gauche, Au centre, À droite ou Derrière, puis Enregistrer.

Plus tard · quand une nouvelle version est annoncée

Mettre à jour l’application

La page Casques du site signale les casques concernés par « mise à jour disponible ». La mise à jour s’installe par-dessus l’ancienne version : les films restent dans le casque et il reste relié au site. Rien à refaire, aucun code à retaper.

  1. Sur le site, page Casques, vérifiez la date de dernière mise à jour dans le cadre Application casque, puis cliquez sur Télécharger DLPAlexandre.apk.
  2. Remplacez l’ancien fichier du Bureau par le nouveau. Gardez un seul DLPAlexandre.apk pour ne pas vous tromper.
  3. Ouvrez Meta Quest Developer Hub, branchez le casque, pastille verte Active dans Device Manager, comme à l’étape 4.
  4. Zone Apps, Add Build, choisissez DLPAlexandre.apk sur le Bureau, Ouvrir. Attendez la fin, une à deux minutes.
  5. Débranchez, ouvrez DLPAlexandre dans le casque par le chemin A ou B de l’étape 6. Les films sont là, sans code à 6 chiffres.
  6. Sur le site, la mention « mise à jour disponible » disparaît de la ligne du casque dès que l’application a contacté le serveur.
Ne désinstallez pas l’ancienne version

Désinstaller efface les films et le lien avec le site. Il faudrait retaper un code et tout retélécharger. La mise à jour se fait toujours par-dessus.

Un message INSTALL_FAILED_UPDATE_INCOMPATIBLE veut dire que le fichier ne vient pas du site. N’effacez rien et appelez votre prestataire.

Les anciennes versions « VR Cinema Quest »

Jusqu’à la version 1.1.6, l’application s’appelait VR Cinema Quest dans le casque. Après la mise à jour, elle s’appelle DLPAlexandre, au même endroit dans Sources inconnues, avec les mêmes films.

Ne faites pas ça pour « réparer »

Ne supprimez pas le casque sur le site : vous perdez son historique et il faudra retaper un code. Utilisez Forcer la mise à jour.

Ne désinstallez pas l’application dans le casque sans en parler à votre prestataire. Selon la version déjà présente, la désinstallation efface le lien local et oblige à tout refaire.

N’installez pas un fichier dont le nom contient STAGING sur ce site de production.

Le jour de l’événement

  • La synchronisation a été faite la veille, pas le matin.
  • Chaque casque a un nom clair, est chargé, et affiche À jour.
  • Un film a été lancé dans un vrai casque, image dans le bon sens.
  • Le câble USB, le fichier .apk et Meta Quest Developer Hub restent dans le sac, au cas où un casque devrait être réinstallé.
Au quotidien, après cette installation

Site, films, playlist, application ouverte sur les casques, attendre À jour. Ensuite le Wi-Fi peut être coupé : ce qui est déjà dans le casque reste lisible.

Seulement si Device Manager reste vide

Secours : le pilote USB

Windows ne sait pas parler au casque tant que ce pilote n’est pas installé. Meta Quest Developer Hub le fait souvent tout seul. Cette page ne sert que s’il ne l’a pas fait.

Fermez d’abord Meta Quest Developer Hub, complètement, avant les étapes ci-dessous.

A. Installer le pilote

  1. Téléchargez les pilotes sur cette page, bouton Download. https://developers.meta.com/vr/downloads/package/oculus-adb-drivers/
  2. Clic droit sur le fichier zip téléchargé → Extraire tout → Extraire.
  3. Ouvrez le dossier extrait, puis le sous-dossier usb_driver, jusqu’à voir le fichier android_winusb.inf.
  4. Clic droit sur android_winusb.inf → Installer. Acceptez la question de Windows. Si Windows dit qu’il ne peut pas vérifier l’éditeur, choisissez Installer quand même.

S’il n’y a pas de ligne « Installer » dans le clic droit :

  1. Clic droit sur le bouton Démarrer → Gestionnaire de périphériques.
  2. Cherchez une ligne avec un triangle jaune, souvent nommée Quest, Android, ADB Interface ou Périphérique inconnu.
  3. Clic droit sur cette ligne → Mettre à jour le pilote → Parcourir mon ordinateur pour rechercher des pilotes.
  4. Choisissez le dossier usb_driver. Cochez Inclure les sous-dossiers. Suivant.
  5. Si Windows hésite sur l’éditeur du pilote, installez quand même.

Débranchez le casque, rebranchez-le sur un port à l’arrière, mettez-le sur la tête, et acceptez à nouveau le débogage USB en cochant « toujours ». Rouvrez Meta Quest Developer Hub. Si le casque apparaît, retournez à l’étape 5 et ignorez la partie B.

B. Installer le fichier à la main

Uniquement si le glisser-déposer a échoué alors que le casque était bien visible. Fermez Meta Quest Developer Hub avant, sinon les deux programmes se coupent la parole.

  1. Créez un dossier C:\vr. Pas d’accent, pas d’espace. Le dossier Téléchargements fait échouer la commande.
  2. Téléchargez « SDK Platform-Tools for Windows » sur cette page. https://developer.android.com/tools/releases/platform-tools
  3. Clic droit sur le zip → Extraire tout. Ouvrez le dossier platform-tools.
  4. Copiez dans C:\vr ces quatre éléments, pas seulement le premier : adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll, et DLPAlexandre.apk.
  5. Ouvrez le dossier C:\vr. Cliquez une fois dans la barre tout en haut, celle qui affiche le chemin. Effacez ce qui s’y trouve, tapez powershell, puis Entrée. Une fenêtre bleue s’ouvre.
  6. Copiez la première ligne, collez-la dans la fenêtre bleue, Entrée.
    .\adb.exe devices
    Vous devez lire une ligne qui finit par le mot device. Pas unauthorized, pas une liste vide.
  7. Seulement dans ce cas, copiez la seconde ligne, collez-la, Entrée. Attendez le mot Success. Ne coupez pas la ligne en deux.
    .\adb.exe install -r .\DLPAlexandre.apk
